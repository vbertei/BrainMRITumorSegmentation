# Brain MRI Tumor Segmentation
Project for the module of _Computer Vision_ for the course of Multimedia Information Retrieval and Computer Vision of the Master Degree of Artificial Intelligence and Data Engineering, University of Pisa.

The project consists in a single Colab notebook with all the necessary matierials inside.
Due to file size limits, the notebook cannot be visualized directly on the browser.
Due to compatibility issues, some sections of the cell outputs may not be visualized correctly on your local machine after the notebook download.

Therefore, we recommend opening the notebook directly on Colab at the following link: [Colab Notebook](https://colab.research.google.com/drive/1zSegXG4LUvpuP8BQPghji0i6_JELaMi0?usp=sharing).
